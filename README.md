# product-analytics-basics
# Анализ продаж супермаркета и базовая продуктовая аналитика

## 📌 Описание проекта
Данный проект посвящен анализу транзакционных данных супермаркета. Главная цель — очистить сырые данные, рассчитать ключевые продуктовые метрики и выявить бизнес-тренды для поиска точек роста. 

## 🛠 Стек технологий
- **Python** (Pandas, NumPy)
- **Визуализация данных** (Matplotlib, Seaborn)
- **Jupyter Notebook**

## 🎯 Выполненные задачи
1. **Очистка и предобработка данных:** Обработка пропущенных значений, исправление типов данных (парсинг дат и строковых значений выручки).
2. **Расчет продуктовых метрик:** Вычисление среднего чека (AOV), средней выручки на пользователя (ARPU) и общей суммы продаж.
3. **Анализ трендов:** Группировка ежедневной выручки для выявления сезонности, определение наиболее прибыльных категорий товаров и филиалов.

## 📈 Ключевые выводы и бизнес-рекомендации
- **Динамика выручки:** Наблюдаются выраженные пики продаж в выходные дни. Рекомендуется увеличить маркетинговый бюджет и количество смен персонала в пятницу и субботу.
- **Топ-категории товаров:** Наибольшую выручку приносят "Электронные аксессуары" (Electronic accessories) и "Продукты питания" (Food and beverages). Стоит запустить кампании по кросс-сейлу, сфокусированные на этих категориях.
- **Эффективность филиалов:** Филиал 'C' стабильно показывает более высокий средний чек. Необходимо изучить практики этого филиала (выкладка товаров, работа консультантов) и масштабировать их на филиалы 'A' и 'B'.
